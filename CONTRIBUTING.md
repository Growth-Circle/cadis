# Contributing to CADIS

**CADIS is discontinued.** We do not maintain this repository anymore.
We do not review or merge new pull requests here, and we do not triage new issues.

## Contribute to Seira

Development continues in **[Seira](https://github.com/seira-bot/seira)**.

1. Go to [seira-bot/seira](https://github.com/seira-bot/seira).
2. Read the [Seira contributing guide](https://github.com/seira-bot/seira/blob/main/CONTRIBUTING.md).
3. Open your issue or pull request in the Seira repository.

Thank you to everyone who contributed to CADIS.

## Security

Report security problems in Seira through its
[security policy](https://github.com/seira-bot/seira/blob/main/SECURITY.md).
